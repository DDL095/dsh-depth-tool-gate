# panel-guide — 设置页面板逐 Tab 手册（v0.16.8, 8 Tab）

入口：设置 → 子代理工具面（dsh-depth-tool-gate）。顶栏：enabled 总开关 / autoDenyNew 新工具默认拦截 / 保存（热生效，仅之后创建/恢复的 agent；运行中会话不变）/ 刷新。**版本徽标**（v0.16.8 起）：标题右侧显示「版本 x.y.z」——客户端版（面板 UI 这份代码）与宿主版（裁剪/闸门/台账在跑的那份）**两个数**；两者不一致时显式标出「宿主 x.y.z 待重启」（改了 client.js 刷新浏览器即生效，改了 host 侧必须重启 DSH）。所有时间显示为用户本地时区（存储恒为 UTC ISO）。

| Tab | 名 | 内容与操作 |
|---|---|---|
| 1 | 📋 全局工具面 | 三个**一级折叠区**（v0.16.7 起）：**①已禁用清单(子代理禁用)**（baseline_deny：组级开关 + 逐件勾选 + 🔍；兜底组「➕ 配置内未分组」装未注册/已改名的件，失效残留可就地取消）、**②已禁用清单(主会话禁用)**（main_deny：同构，**独立通道**，不影响子代理）、**③未裁决工具(运行时快照)**（来源筛选下拉；每行两层独立勾选 + 🔍；🤖 批量解读提示词 ≤8/批）。顶部一行总览（两层都禁 N · 仅子代理禁 N · 仅主会话禁 N）。中段=**主会话禁用清单 main_deny 批量编辑区**（textarea，逐行/逗号分隔）。底部=**🟢 常用件区**（逐件用途说明 + 两层勾选）。底部折叠图例「为什么看不见/被拦」两轴 |
| 2 | 🧭 主会话与访问 | 两个**一级折叠区**（v0.16.7 起），各自带**生效逻辑**说明：①**preset 访问控制**（勾选的 preset 禁止作为子代被派单；生效于**子代创建的那一刻** ⇒ 限制到最小回报面（note_search + send_message），最小面不可用/裁剪抛错 ⇒ **fail-closed** 裁掉全部已知工具；depth0 手开不受限；`list_agent_presets` 同步隐藏）；②**主会话按角色禁用**（main_preset_extra_deny：生效于**主会话创建/恢复的那一刻** ⇒ 与 main_deny **叠加**；该角色若配 main_preset_allow 则名单即全部、不再叠加；未配时回落共用键 preset_allow[角色] 且在主会话侧是 keep-only 语义 ⇒ 台账记 allow-fallback 事件）。高级折叠=正面清单与原始 JSON |
| 3 | 👥 子代理按角色 (v0.11 更名) | 原「按角色禁用」：该 preset 子代的最终禁用面（全局底线∩角色例外）；「恢复继承全局」清例外；高级=三名单原始 JSON |
| 4 | 🧪 能力标签 | dispatch_composed 标签表；**来源标注**（内置缺省 DEFAULT_CAPABILITIES / 自定义表 config.capabilities 整体覆盖内置）；折叠说明「❓ 能力标签从哪来? 其他用户怎么自动看到?」= 缺省标签表**随插件发布**（别人装上就有，无需手工配置）+ 决策面目录**自动生成并落盘**（profile 目录 capability-catalog.txt，面板刷新即重生成 ⇒ 热生效）+ 目录只注入决策面角色（当前 cordis-router）；⭐可带队=可再派一级孙代 |
| 5 | 📝 工具说明 (v0.16.0 新增) | **逐件用途说明台账**：计数条（总数/达标/待补/缺说明/人工/自动/运行时不可见）+ 台账文件路径（profile 目录 `annotations.json`）；**待标注队列**可就地补写说明（人工优先，永不被自动初标覆盖）；判据三条（非空 / ≥12 字节 / 相对工具名有信息增益） |
| 6 | 📊 调用频率 (v0.11 落盘) | 总量/去重/Top30；**按会话明细折叠**（最近 40 个：最近活动/会话尾号/角色/调用数/Top 工具；快照落盘 depth-tool-gate.usage.json，重启不清零，每 500 次调用或每次拉取时写入）；按 preset 分桶 |
| 7 | 📜 裁剪台账 (v0.11 白话化) | 每行=一个会话/子代理诞生时的裁剪快照；**红色 ev 行=治理事件**（lock-corrupt/config-corrupt/gate-error/role-brief-missing 及错误摘要）；列头白话（时间本地/会话/深度/角色或事件/禁用/pending/裁后可见/缺名或错误） |
| 8 | 🚦 闸门与发现 (v0.11 白话化+归因) | 白话说明（只盯新工具）；pending 四键（🚫子代理禁/🧭主会话禁/🔍解读/✅放行）；**名单失效件逐件归因表**（域会话专属 MCP/来源停用可复装/疑改名 三态）；🔒**无法关闭(preset-scoped, restrict 不可达)**名单（= lock 的 `forced` 态，由 `maxDepth=12` 总闸管辖）；lock 原始 JSON |

保存语义：全部写 `depth-tool-gate.config.json`（host 热读）——**仅对之后创建/恢复的 agent 生效**（恢复会话重新过 agent/created 闸），运行中会话不动。main_deny 保护集 18 件由 host status 下发（单一权威源，客户端镜像仅回退兜底）。
