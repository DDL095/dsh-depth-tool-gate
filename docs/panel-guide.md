# panel-guide — 设置页面板逐 Tab 手册（v0.11, 7 Tab）

入口：设置 → 子代理工具面（depth-tool-gate）。顶栏：enabled 总开关 / autoDenyNew 新工具默认拦截 / 保存（热生效，仅之后创建/恢复的 agent；运行中会话不变）/ 刷新。所有时间显示为用户本地时区（存储恒为 UTC ISO）。

| Tab | 名 | 内容与操作 |
|---|---|---|
| 1 | 📋 全局工具面 | 双栏可折叠（上栏默认收起+计数摘要）。上栏=已禁用清单（baseline_deny 分组勾选，每件带 🔍 解读）；下栏=未裁决工具（运行时快照，**来源筛选下拉**；每行两层独立勾选：子代理禁/主会话禁(保护件置灰)+🔍；🤖 批量解读提示词 ≤8/批）。中段=**主会话禁用清单 main_deny 编辑区**（v0.11 从 Tab🧭 迁入）。底部折叠图例「为什么看不见/被拦」两轴 + KEEP |
| 2 | 🧭 主会话与访问 (v0.11 重组) | **主功能=preset 访问控制**（勾选的 preset 禁止被派单为子代：最小回报面+台账；depth0 手开不受限）。下半=**主会话按角色禁用**（main_preset_extra_deny：手开该 preset 的主会话在 main_deny 之上叠加勾选；高级折叠=正面清单 main_preset_allow 与原始 JSON；子代侧配置在 Tab👥，两场景 v0.11 起分离，host 侧回落兼容旧共用键） |
| 3 | 👥 子代理按角色 (v0.11 更名) | 原「按角色禁用」：该 preset 子代的最终禁用面（全局底线∩角色例外）；「恢复继承全局」清例外；高级=三名单原始 JSON |
| 4 | 🧪 能力标签 | dispatch_composed 标签表；自定义表整体覆盖内置；⭐可带队=可再派一级孙代 |
| 5 | 📊 调用频率 (v0.11 落盘) | 总量/去重/Top30；**按会话明细折叠**（最近 40 个：最近活动/会话尾号/角色/调用数/Top 工具；快照落盘 depth-tool-gate.usage.json，重启不清零，每 500 次调用或每次拉取时写入）；按 preset 分桶 |
| 6 | 📜 裁剪台账 (v0.11 白话化) | 每行=一个会话/子代理诞生时的裁剪快照；**红色 ev 行=治理事件**（lock-corrupt/config-corrupt/gate-error/role-brief-missing 及错误摘要）；列头白话（时间本地/会话/深度/角色或事件/禁用/pending/裁后可见/缺名或错误） |
| 7 | 🚦 闸门与发现 (v0.11 白话化+归因) | 白话说明（只盯新工具）；pending 四键（🚫子代理禁/🧭主会话禁/🔍解读/✅放行）；**名单失效件逐件归因表**（域会话专属 MCP/来源停用可复装/疑改名 三态）；🔒作用域外名单；lock 原始 JSON |

保存语义：全部写 `depth-tool-gate.config.json`（host 热读）——**仅对之后创建/恢复的 agent 生效**（恢复会话重新过 agent/created 闸），运行中会话不动。main_deny 保护集 19 件由 host status 下发（单一权威源，客户端镜像仅回退兜底）。
